# 책숲 도서관

따뜻한 책장, 둥근 독서 테이블, 달빛 창가가 있는 작은 3D 도서관입니다. Three.js 기본 도형으로 만들었으며 경쟁·점수 없이 친구와 쉬어갈 수 있습니다.

- [도서관](https://seonyoungyoo16.github.io/little-lantern-library/)
- 배포·다운로드 결과: `책숲 도서관 - 친구와 함께.html` 한 파일. 이미지·모델·글꼴·라이브러리를 따로 받을 필요가 없습니다. 친구 연결에는 인터넷과 Firebase가 필요합니다.
- 책의 숲이나 둥근 탁자 근처에서 **탁자에 앉아 읽기**를 누르면 빈 의자까지 걸어가 앉습니다. 세 권의 짧은 창작 이야기마다 처음부터 끝까지 이어지는 5쪽이 있습니다. **이전 쪽·다음 쪽**을 누를 때 내용과 실제 3D 책장이 함께 바뀝니다. 자동으로 책장을 넘기지 않습니다. 친구에게도 앉은 자세와 넘기는 방향·진행이 보입니다.
- **다른 책**으로 고르고 **그만 읽고 일어나기**로 언제든 멈춥니다. 읽던 쪽은 브라우저에 남습니다. 마지막 쪽의 **다 읽었어요**를 누르면 책마다 한 번 스탬프 안내가 나옵니다. **스탬프 찍으러 가기**를 고르면 의자에서 나와 책갈피 책상으로 걷고, **계속 쉬기**를 고르면 그대로 앉아 있습니다. 다시 읽을 수 있습니다.
- 독서 의자 네 개 중 친구가 앉아 있거나 걸어가는 자리는 피합니다. 걷는 중에는 **그만하기**, 바닥 클릭, 이동키로 취소할 수 있습니다. 의자 선택은 기존 접속 상태의 허용 필드를 사용하며 서버 규칙은 바꾸지 않습니다.
- 달빛 창가의 나무 의자는 바깥 하늘을 향합니다. **창가에 앉아 쉬기**를 누르면 가까운 어깨 너머 시점으로 밤하늘을 봅니다. 작은 자체 생성 배경에 달의 음영·은은한 구름·밝기가 다른 별을 그렸고, 별은 유리 범위 안에서 창틀 뒤에 있습니다. 하늘은 분위기를 위한 연출이며 현재 위치의 실시간 성도가 아닙니다.
- 책갈피 책상에서 **책갈피 남기기**를 합니다. 친구에게도 책 종류·읽기·앉기·도장 찍기·손 흔들기가 보입니다.
- **내 책갈피**에는 만든 이름·책·날짜가 이 브라우저에 최대 30개 저장됩니다. 서버에 개인 독서 기록을 보내지 않습니다.
- 바닥 클릭·터치로 걷고 화면 드래그로 시점을 돌립니다. PC에서는 WASD·방향키, E·스페이스를 사용할 수 있습니다. 소리는 기본으로 꺼져 있습니다.

## 도서관 고양이 귤이

주황색 고양이 귤이가 도서관에서 생활합니다. 책장 사이 산책·뛰기·그루밍·식사·모래 화장실·잠자기를 스스로 반복합니다. 침대, 밥그릇과 물그릇, 스크래처, 장난감, 모래 화장실은 왼쪽의 작은 고양이 쉼터에 모았습니다. 화장실에서는 몸을 웅크리고 볼일을 본 뒤 앞발로 모래를 덮습니다. 잠들 때는 전용 앞발·꼬리 자세로 넓은 쿠션 위에 눕습니다.

3D 고양이 또는 머리 위 이름을 누르세요. 발바닥 버튼으로도 찾을 수 있습니다. **쓰다듬기·장난감 놀이·간식 주기**를 고르면 캐릭터가 가까이 걸어가 실제로 손을 뻗거나 장난감·간식을 듭니다. 귤이도 몸을 비비거나 뛰어오르고 먹는 모습으로 반응합니다. **그만하기** 또는 바닥·이동키로 다가가기를 취소할 수 있습니다.

공통 시각과 친구 방 식별자로 같은 생활 경로를 계산합니다. 고양이 전용 서버나 별도의 상태 쓰기는 없습니다. 교감할 때는 기존 캐릭터 접속 필드로 종류·진행을 전달해 친구 화면에도 캐릭터와 귤이의 반응을 표시합니다. 두 사람이 동시에 시도하면 한 사람에게 먼저 반응합니다. 창을 숨기면 진행 중인 교감을 해제합니다. 네트워크 지연에 따라 아주 짧은 보간 차이는 있을 수 있습니다.

## 친구와 세 공간 오가기

친구 초대 버튼에서 **같은 초대 주소**를 공유하세요. 정상 클라이언트에서 방마다 최대 네 명이 입장합니다. 서버가 악의적인 클라이언트의 인원수를 판정하는 구조는 아닙니다.

겨울 마을·수족관·도서관의 이동 버튼은 같은 친구 그룹을 유지합니다. 닉네임과 캐릭터 종류를 이어서 사용하고 자동 입장합니다. 다른 공간에 있는 친구의 이름과 **따라가기**가 표시됩니다. 친구가 강제로 이동되지는 않습니다.

같은 24자리 그룹 식별자에 겨울은 접두어 없음, 수족관은 `aq_`, 도서관은 `lb_`를 붙입니다. 공간별 좌표와 행동은 별도 레코드에서 처리합니다. 세션 저장이 차단되면 목적지에서 이름을 다시 입력할 수 있지만 친구 방 주소는 유지됩니다. 활동 도중 진행 상황은 다른 공간으로 가져오지 않습니다.

## 개발과 배포

```powershell
npm ci
npm run build
npm test
npm run preview
```

로컬 미리보기는 http://127.0.0.1:4190/little-lantern-library/ 입니다. 형제 경로에 겨울·수족관 프로젝트가 있으면 같은 서버에서 왕복을 점검할 수 있습니다. `npm run test:live`는 실제 Firebase에 임시 익명 계정 두 개와 무작위 도서관 방을 만들어 검사한 뒤 자신의 시험 데이터만 정리합니다.

- `library.js`: 공통 3D 기반·캐릭터·이동·카메라
- `library-scene.js`: 도형 기반 도서관 장면·가구 충돌
- `library-actions.js`: 책·도장·개인 책갈피
- `library-game.js`, `library-loop.js`: 행동·입력·UI·애니메이션
- `library-cat.js`: 기본 도형 고양이·용품·생활 경로·교감·공통 시각 계산
- `multiplayer.js`: Firebase 입장·행동 보간·접속 정리·알림
- `world-travel.js`, `.css`, `.html`: 세 프로젝트에 공통으로 포함되는 공간 이동
- `multiplayer.html`: 모바일 UI 원본
- `build-multiplayer.cjs`: 코드·SDK·글꼴을 인라인으로 묶어 `dist/index.html`, `docs/index.html`, 다운로드 HTML 생성

GitHub Pages는 `main`의 `/docs`를 게시합니다. 라이브러리와 글꼴을 내장하므로 기본 화면은 추가 자산 요청 없이 동작합니다. 책의 짧은 이야기는 이 소스에 작성한 문장입니다. AI API를 사용하지 않습니다.

## 연결 범위

기존 `snowyroom-8a8a5` 프로젝트의 익명 인증과 Realtime Database를 사용합니다. **세 공간은 기존 Firebase Spark 무료 할당량을 함께 사용합니다.** 새 유료 서비스·서버·데이터베이스 규칙 변경은 없습니다. 사용량은 Firebase 콘솔에서 확인합니다. `firebase-config.json`은 공개 웹 연결 설정이고 관리자 자격 증명이 아닙니다.

서버로 보내는 정보는 닉네임·캐릭터·좌표·행동·책 종류·쪽과 넘김 진행·접속 시각입니다. 타인의 캐릭터 레코드 수정은 금지합니다. 방 목록 읽기를 허용하지 않습니다. 책갈피·완독 기록·마이크·카메라·실제 위치는 전송하지 않습니다. 모바일 해상도·빛 먼지 입자를 제한하고 정적 도형을 색상별로 합치며 실시간 그림자 맵은 사용하지 않습니다.

[AstronomyAPI 공식 문서](https://docs.astronomyapi.com/)의 비밀키 인증 방식을 검토했습니다. 공개 HTML에 비밀키를 포함하지 않도록 이 버전에서는 호출하지 않습니다. 별도 서버·API 계정·천문 이미지 요청을 추가하지 않았습니다.

데스크톱 입장 알림은 사용자가 켜고 브라우저 권한을 허용했을 때 열린 탭에서만 제공합니다. 닫힌 탭 푸시는 지원하지 않습니다. 실제 휴대폰·Safari 성능과 Windows 알림 배너는 별도 확인 범위입니다.
