# 책숲 도서관 검증 · 2026-11-07

## 자동 검사

- 입구·책장·창가·책갈피 책상 사이의 경로 및 구간이 가구 충돌을 피함
- 실제 Three.js 장면에서 책 펼치기·페이지 넘김·양손 자세·세 가지 표지, 독립적인 친구 책과 창가 앉기 자세
- 독서 책을 가슴 높이로 내리고 얼굴에서 떨어뜨린 자세, 친구에게도 같은 소품 위치 적용
- 도장 소품·책갈피 표시·완료 저장·잘못된 기록 정리·최신 30개 제한·기록 목록
- 실제 peer 갱신 코드에서 책 선택과 도장 진행 복호화, 중단 시 소품 숨김, 퇴장 시 정리
- 개인 책갈피 기록이 네트워크 상태에 포함되지 않음
- 세 공간의 방 접두어와 그룹 식별자 유지, 자동 입장·이름·캐릭터 보존, 이동 전 접속 정리
- 두 다른 공간의 친구 구독·따라가기·만료 접속 제외·입장 알림 중복 억제
- 번들 스크립트 문법, 외부 시각 자산 없음, 배포본과 다운로드 단일 HTML의 동일성
- 겨울 마을의 눈사람·모닥불·썰매 검사와 수족관의 먹이·휴식·사진 동작 검사 통과

## 실제 Firebase

독립적인 임시 익명 사용자 두 명으로 도서관 `lb_` 방에 입장하고 상태 읽기·쓰기를 검증했습니다. 타인의 캐릭터 변경·삭제, 범위 밖 좌표·추가 필드, 인증 없는 읽기와 방 목록 읽기는 거부되었습니다. 기존 허용 필드로 독서·휴식·도장·인사와 책 종류·도장 진행을 전송했습니다. 자신의 임시 레코드와 계정만 정리했습니다. 서버 규칙·요금제 변경은 없습니다.

## 브라우저

- 독립적인 IAB 토끼와 Chrome 곰으로 실제 같은 방 접속, 닉네임·캐릭터·행동 공유
- 책의 숲까지 걷기, 책 펼치기와 다음 책, 상대 화면에 실제 펼친 책과 독서 상태
- 창가 의자에 앉은 자세, 상대 화면의 창가 휴식 상태
- 책갈피 책상까지 걷기, 실제 책·도장 동작, 상대 화면의 책갈피 남기는 상태
- 완료 후 이름·책·날짜 기록, 공간 왕복으로 페이지가 다시 로드되어도 기록 보존
- 두 브라우저의 도서관 → 겨울 → 수족관 → 도서관 이동, 친구 이름과 따라가기, 자동 입장과 동일 프로필
- 320×640 및 390×844 모바일 뷰포트에서 이동·행동 버튼과 기록 창 확인
- 공개 GitHub Pages 세 주소 HTTPS 200 및 로컬 배포 HTML 내용 일치
- 공개 도서관에서 독립적인 두 브라우저 연결, 낮춘 독서 자세 공유, 세 공간 왕복 자동 입장 확인
- 브라우저 오류 로그 없음, 임시 모바일 뷰포트 복원

실제 휴대폰·Safari·물리 터치 성능, Windows 알림 배너는 미검증입니다. 닫힌 탭 푸시는 지원하지 않습니다. 모바일 점검은 데스크톱 브라우저의 뷰포트 조절을 사용했습니다.

## 둥근 탁자에서 앉아 읽기 · 2026-11-07

- 책장 또는 탁자 의자 근처의 읽기 버튼 → 가구를 피해 빈 의자 뒤까지 걷기 → 의자에 앉기 → 책 펼침과 페이지 넘김
- 네 의자의 좌표·탁자를 향한 방향·앉은 높이, 굽힌 다리, 얼굴에서 떨어뜨린 책 위치를 실제 Three.js 객체와 이동 루프로 검사
- 다른 친구가 앉은 자리 및 걸어가는 자리 제외, 동시에 같은 의자를 고른 경우 한 세션이 다른 의자로 이동, 자리 없음·취소 처리 검사
- 책 덮기 후 가구와 겹치지 않는 의자 뒤로 나와 서기, 다리·소품 복원 및 자리 해제
- 실제 peer 갱신 코드로 처음 합류한 친구의 앉은 높이·책·다리 자세와 독서 종료 복원 확인
- 기존 Firebase 허용 필드로 네 의자 예약 값 쓰기 성공, 서버 규칙 변경 없음
- 실제 IAB 토끼와 Chrome 곰이 같은 둥근 탁자의 서로 다른 의자에 앉음. 상대 화면에서도 독서 자세·펼친 책·책 넘김 확인
- 실제 화면에서 다음 책, 책 덮고 일어나기 확인. 두 브라우저 오류 로그 없음

## 하늘을 보는 창가·책 전체 읽기 · 2026-11-07

- 창가 소파를 바깥쪽을 향한 나무 의자 네 개로 교체. 가까운 어깨 너머 시점에서 창밖의 달·구름·별·먼 능선 확인
- 하늘은 1024×428 자체 생성 텍스처 한 장. 유리 범위 안의 평면이 모든 창틀보다 뒤에 있어 별이 창틀 앞에 겹치지 않음
- 창가 의자 방향·실내 카메라 위치·퇴장 시 가구와 겹치지 않는 위치, 입구·책장·창가·책갈피 책상 동선 검사
- 작은 표지판 옆의 격자 연결 구간도 충돌을 확인하도록 길찾기 보강
- 세 권 각각 5쪽의 완결된 창작 이야기. 입력 없이 쪽이나 3D 책장이 자동으로 넘어가지 않음
- 이전·다음 쪽, 다시 읽기, 다른 책, 읽기 중단, 쪽별 내용 변경과 3D 넘김 방향·진행 검사
- 마지막 쪽에서 다 읽었어요 선택 후 책마다 한 번만 스탬프 제안. 계속 쉬기·스탬프 책상으로 이동, 로컬 읽던 쪽·완독 저장 검사
- 기존 네트워크 필드에서 세 책×다섯 쪽×양방향 넘김·진행 값 복호화, 친구의 앉은 자세와 넘김, 늦게 합류한 친구에게 완료한 넘김을 다시 재생하지 않는 처리 검사
- 실제 Firebase에 새 페이지·진행 값 및 앉은 높이 쓰기 허용 확인. 보안 규칙·요금제 변경 없음
- 실제 화면에서 1~5쪽 순서·이전 쪽·완독 안내·스탬프 책상으로 이동 확인. 브라우저 오류 로그 없음
- AstronomyAPI의 비밀키 인증 방식을 공식 문서에서 검토하고 이번 공개 단일 HTML에는 통합하지 않음. 실시간 천문 자료를 사용한다고 주장하지 않음

## 주황 고양이 귤이 · 2026-11-07

- 둥근 큰 얼굴·검은 눈과 하이라이트·크림색 발·가는 수염·짧은 몸의 기본 도형 고양이. 몸 전체를 감싸던 굵은 고리 무늬를 제거
- 용품을 왼쪽 쉼터 한곳에 모음. 장식 묶음의 실제 범위가 왼쪽 구역 안에 있는지 검사
- 넓고 낮은 쿠션, 잠자는 전용 앞발·옆으로 말린 꼬리 사용. 머리·몸·앞발·꼬리의 실제 정점이 쿠션 위에 있고 가장자리 밖으로 나가지 않는지 검사
- 공통 시각·방 식별자로 동일한 산책·빠른 달리기·그루밍·식사·화장실·수면 순환. 각 생활 상태의 실제 3D 자세·소품·가구를 피하는 경로 검사
- 화장실에서 웅크리기·작은 배설물·모래 덮기·덮은 후 사라지기 검사
- 실제 3D 고양이 클릭 판정, 다가가기·취소, 쓰다듬기·장난감·간식 소품, 동작 종료·정리 검사
- 실제 peer 코드로 장난감과 고양이 반응 공유, 기존 허용 필드의 종류·진행 값 왕복 검사. 실제 Firebase 쓰기 허용 확인
- 브라우저에서 고양이·교감 메뉴·자동 접근·장난감 놀이와 상대 화면의 활동 표시 확인. 오류 로그 없음
- 고양이 교감 중에는 가까운 시점을 사용하고 이름표를 숨겨 손과 소품이 잘 보이게 조정

## 귤이 찾기·교감 거리·잠 깨우기 수정 · 2026-11-07

- 발바닥의 `귤이 찾으러 가기`가 실제로 이동을 시작하고, 가구를 피해 현재 고양이 위치까지 따라간 뒤 약 3.2 거리에서 메뉴를 엽니다. 찾기만으로 잠을 깨우지 않습니다.
- 생활 순환의 모든 지점까지 도착, 이동 중인 고양이 추적, 길 재계산, 접근 취소, 독서 의자 예약 값과의 충돌 방지를 실제 이동 루프로 검사했습니다.
- 쓰다듬기 2.2, 장난감 2.9, 간식 2.5 간격을 유지합니다. 이미 너무 가까우면 먼저 뒤로 물러섭니다. 실제 3D 몸체 범위가 겹치지 않고 친구의 교감도 같은 간격을 쓰는지 검사했습니다.
- 교감·메뉴 카메라를 뒤로 물려 주변 바닥과 캐릭터가 함께 보이게 했습니다.
- 잠든 고양이 자체나 이름표를 누르면 귀를 눕히고 눈썹을 찡그리며 꼬리를 휘두르는 심술 동작이 나옵니다. 수면·심술·화장실 중에는 세 교감 버튼과 실제 실행 함수 모두 잠깁니다.
- 심술은 약 5초 후 가라앉고 생활 순환으로 돌아갑니다. 메뉴를 연 채 기다리기, 깨우기 중 취소·이동, 친구의 교감 취소로 대기 시간을 건너뛰지 못하는지 검사했습니다.
- 기존 허용 상태 필드의 0.695~0.700 구간으로 깨우기를 공유하며 간식·손 흔들기와 구분합니다. 친구 화면의 심술·버튼 잠금 및 실제 Firebase의 경계 값 쓰기 허용을 확인했습니다. 보안 규칙·요금제 변경은 없습니다.

## 손이 닿는 교감 거리 보정 · 2026-11-07

- 사용자가 실제 접촉을 원한다는 피드백에 따라 최종 간격을 쓰다듬기 1.14, 장난감 1.55, 간식 1.28로 조정했습니다. 여유 있는 카메라 거리는 유지합니다.
- 쓰다듬을 때 귤이가 옆으로 돌아선 후 캐릭터가 몸을 낮춥니다. 손 위치를 실제 고양이 머리 메시의 표면에 맞추며, 간식은 올라온 주둥이 앞에 건넵니다. 장난감을 잡는 손도 실제 손잡이 위치에 맞춥니다.
- 접촉 부위와 몸통·머리를 구분해 검사합니다. 교감 전 구간에서 몸통·얼굴 범위의 관통이 없고, 안정된 동작에서 손의 실제 모양과 털 표면, 손과 장난감 손잡이, 간식과 입 위치가 닿는지 검사합니다.
- 접근의 도착 허용 범위도 줄여, 목표보다 가까운 위치에서 교감을 시작하지 않도록 했습니다. 친구 세 캐릭터와 서로 다른 방향에서도 같은 접촉·분리, 종료 후 팔 길이·발 위치 복원을 검사합니다.
- 같은 배포 HTML의 실제 장면·동작 함수를 사용하는 로컬 자세 미리보기에서 데스크톱과 390×844 화면의 쓰다듬기·간식·장난감을 확인했습니다. 이 미리보기는 온라인에 접속하지 않는 시각 검사이며 배포 파일에는 포함하지 않습니다. 친구 접촉은 별도의 실제 peer 갱신 코드 검사로 확인했습니다.

## 책장 앞에서 고르고 탁자에서 읽기 · 2026-11-07

- 책 선택 위치를 책장 바로 앞의 서 있는 자리로 옮겼습니다. 입구·탁자·다른 장소에서 `책 고르러 가기`를 누르면 가구를 피해 책장까지 걷고, 도착해야 세 권의 선택창이 열립니다.
- 제목을 고른 후에만 빈 독서 의자를 예약하고 이동해 앉습니다. 책장으로 걷는 동안에는 제목을 바꾸거나 의자를 예약하지 않으며, 선택창을 닫거나 이동을 취소하면 남는 독서 예약이 없습니다.
- 앉아 있는 동안 `다른 책 고르러 가기`를 누르면 먼저 책을 덮고 일어나 책장으로 돌아갑니다. 그 자리에서 새 제목을 골라야 다시 의자로 이동합니다. 앉은 상태에서 선택 함수를 호출해도 제목이 바뀌지 않는 것을 검사했습니다.
- 네 의자 예약·동시 선택 양보, 페이지 진행·완독 스탬프·저장, 친구 독서 자세, 귤이 교감 회귀 검사를 통과했습니다.
- IAB와 독립된 Chrome에서 책장 앞 선택 → 의자 독서 → 책장으로 돌아가 다른 책 선택을 확인했습니다. 390×844 화면에서 캐릭터가 실제 책장 앞에 서 있는 모습을 확인했습니다.
