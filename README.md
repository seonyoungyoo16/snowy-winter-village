# 눈 내리는 겨울 마을

Three.js 기본 도형으로 만든 작은 겨울 마을입니다. 눈을 굴려 눈사람을 만들고, 모닥불에서 손을 녹이고, 썰매를 탑니다.

친구 초대 버튼으로 복사한 **같은 초대 주소**에 접속하면 최대 네 명의 캐릭터와 움직임을 함께 봅니다. 기본 주소를 새로 열면 별도의 마을 주소가 생성됩니다. 눈사람은 브라우저 로컬 저장을 유지합니다.

## 실행

- 공개 웹사이트: https://seonyoungyoo16.github.io/snowy-winter-village/
- `눈 내리는 겨울 마을 - 친구와 함께.html`: Three.js, 글꼴, Firebase SDK를 포함하는 단일 HTML입니다. 멀티플레이에는 인터넷 연결이 필요합니다.
- `눈 내리는 겨울 마을.html` 및 `game.html`: 기존 싱글플레이 버전을 보존했습니다.

## 개발과 점검

Node.js 20 이상에서 다음 명령을 사용합니다.

```sh
npm ci
npm run build
npm test
npm run test:live
node preview-multiplayer.cjs
```

`test:live`는 설정된 Firebase에 임시 익명 사용자 두 명과 임시 마을을 만들어 접근 규칙과 동작 상태 전송을 검증한 후, 이 실행에서 생성한 기록과 계정을 정리합니다.

## 연결과 저장

- Firebase Authentication의 익명 로그인과 Realtime Database를 사용합니다.
- 위치는 움직일 때 최대 초당 다섯 번 전달하고, 화면에서는 사이를 부드럽게 연결합니다. 대기 상태는 드문 주기로만 갱신합니다.
- 연결 종료 정리를 첫 기록 저장 전에 예약하며, 재연결할 때 다시 등록합니다.
- 방 목록은 읽을 수 없고, 초대 주소의 무작위 방 식별자를 알아야 해당 방에 접속할 수 있습니다. 초대 주소를 아는 익명 사용자는 그 방의 캐릭터 정보를 볼 수 있습니다.
- 각 캐릭터 기록은 소유한 인증 사용자만 수정하거나 삭제할 수 있습니다. 위치, 닉네임 길이, 행동 값과 허용 필드를 서버 규칙에서도 검사합니다.
- 네 명 정원은 정상 클라이언트의 입장 절차에서 적용합니다. 초대 링크 기반 친구용 초기 버전이며, 서버가 게임 진행을 판정하는 경쟁 게임 구조는 아닙니다.
- 브라우저의 로컬 저장 내용, 마이크, 카메라, 실제 위치는 서버에 보내지 않습니다. AI API를 사용하지 않습니다.
- `firebase-config.json`은 웹 앱에 포함되는 공개 연결 설정이며 관리자 자격 증명을 포함하지 않습니다.

## 배포

`npm run build`가 `docs/index.html`과 단일 HTML 결과물을 만듭니다. GitHub Pages는 `main` 브랜치의 `/docs`를 게시합니다. Firebase는 Spark 무료 요금제를 사용하며, 한도는 Firebase 콘솔의 사용량 화면에서 확인합니다.
