# My Little Village

친구와 천천히 놀 수 있는 세 가지 3D 공간입니다. 소스는 [snowy-winter-village](https://github.com/seonyoungyoo16/snowy-winter-village) 하나에 모았고, 친구들에게 공유한 기존 겨울 마을 주소를 그대로 유지합니다. Three.js 기본 도형과 Firebase 익명 접속을 사용하며 경쟁·점수·AI API가 없습니다.

- [눈 내리는 겨울 마을](https://seonyoungyoo16.github.io/snowy-winter-village/): 눈사람, 모닥불, 썰매, 얼음낚시
- [물결 수족관](https://seonyoungyoo16.github.io/snowy-winter-village/aquarium/): 먹이 주기, 해파리 쉼터, 사진 찍기
- [책숲 도서관](https://seonyoungyoo16.github.io/snowy-winter-village/library/): 앉아서 책 읽기, 창밖 하늘, 완독 스탬프, 주황 고양이 귤이

처음에는 같은 **친구 초대 주소**로 접속하세요. 각 화면의 공간 이동 버튼이 같은 친구 그룹을 유지하고, 닉네임·캐릭터를 이어서 사용합니다. 다른 공간의 친구 이름과 따라가기 버튼도 표시합니다. 정상 클라이언트에서 방마다 네 명까지 만날 수 있습니다.

## 한 저장소에서 개발하기

```powershell
npm ci
npm run build
npm test
npm run preview
```

미리보기: http://127.0.0.1:4191/snowy-winter-village/library/

`winter/`, `aquarium/`, `library/`에 각 공간의 소스·검사·다운로드 HTML이 있습니다. `npm run build`가 세 공간을 함께 빌드해 GitHub Pages의 `docs/`에 모읍니다. Pages 설정은 `main` 브랜치의 `/docs`입니다. 게임별 HTML은 시각 자산과 라이브러리를 내장한 단일 파일이고 친구 연결에는 인터넷이 필요합니다.

`npm run test:live`는 기존 Firebase에 임시 익명 계정과 무작위 시험 방을 만들어 규칙·상태 공유를 확인한 뒤 자신의 시험 데이터만 정리합니다. 관리자 인증 정보는 포함하지 않습니다.

## 기록과 연결

겨울 마을의 기존 저장소에 세 프로젝트의 커밋 이력을 병합해 보존했습니다. [통합 기록](HISTORY.md)에서 가져온 시점을 확인할 수 있습니다. 별도 서브모듈이나 삭제될 저장소를 빌드 의존성으로 사용하지 않습니다.

기존 `snowyroom-8a8a5` Firebase Spark 프로젝트와 규칙을 그대로 사용합니다. 세 공간이 같은 무료 할당량을 함께 사용합니다. 공간별 방 접두어와 브라우저 저장 키를 유지해 기존 눈사람·책갈피·읽던 쪽을 이어갑니다. 실제 사용량은 Firebase 콘솔에서 확인합니다.

도서관 고양이는 공통 시각으로 생활 경로를 계산하고 교감 동작만 기존 친구 상태로 공유합니다. 고양이 용품은 왼쪽 쉼터 한곳에 모았습니다. 책 세 권은 각각 5쪽의 짧은 창작 이야기이며 수동으로 쪽을 넘깁니다. 완독 안내는 책마다 한 번 표시합니다. AstronomyAPI는 비밀키를 공개 HTML에 넣지 않도록 통합하지 않았습니다.

책은 책장 앞에 서서 고른 뒤 둥근 탁자 의자에 앉아 읽습니다. 다른 책을 고를 때도 일어나 책장으로 돌아갑니다.

공간마다 다른 3D 주민이 있습니다. 겨울 주민 **밤이**는 오두막 앞에서 차를 마시고, 수달 사육사 **해리**는 산호 수조에서 먹이를 챙기며, 토끼 사서 **소담**은 책상 뒤에서 책을 살펴봅니다. 옷·도구·주변 소품·대사도 다릅니다. 방문자를 따라가거나 계속 쳐다보거나 자동으로 인사하지 않으며, 가까이에서 먼저 눌렀을 때만 대화합니다. 주인의 PC나 Firebase 접속 상태에 의존하지 않고 네 명의 접속 인원에도 포함되지 않습니다. 고정 배치와 공통 시각에 따른 생활 동작은 같고 대화는 방문자별로 표시됩니다. 주민은 한국 시간의 평일·주말 일과표를 따릅니다. 근무 시간에는 원래 자리에서 일하고, 저녁에는 밤이가 모닥불 옆, 해리가 해파리 쉼터, 소담이 창가에서 쉬며, 늦은 밤에는 꾸벅꾸벅 좁니다. 장소를 바꿀 때는 걸어서 가구를 가로지르지 않고 작게 사라졌다 나타나며, 시간대마다 대사도 달라집니다. 확인용으로 `?routine=work|rest|sleep`을 붙일 수 있습니다.

하늘과 날씨는 한국 시간을 따릅니다. 새벽·낮·노을·밤에 따라 빛과 안개 색이 바뀌고, 겨울 마을의 창문과 가로등은 밤에 밝아집니다. 날씨는 3시간마다 맑음·흐림·눈(비)·함박눈(큰비)·안개 중 하나로 바뀌며, 비가 그친 낮에는 도서관 창밖에 무지개가 뜹니다. 모든 친구가 같은 시각으로 계산하므로 Firebase에 아무것도 쓰지 않아도 같은 하늘을 봅니다. 수족관과 도서관은 실내라 안개가 차지 않고 빛만 달라집니다. 확인할 때는 주소에 `?sky=dawn|day|dusk|night`와 `&weather=clear|cloudy|precip|heavy|fog|rainbow`를 붙여 고정할 수 있습니다.

12월 불빛 축제, 새해 불꽃놀이, 유성우의 밤, 한가위 보름달 같은 **계절 행사**는 한국 날짜에 맞춰 열립니다. 오른쪽 아래 ☺ 버튼으로 하트·웃음 같은 **감정 표현**을 말풍선으로 친구에게 보여줄 수 있고, 겨울 마을에서는 낮에 **연**을, 밤에 **풍등**을 띄울 수 있습니다. 오른쪽 위 책 모양 버튼은 세 공간 공통 **생물 도감**입니다. 겨울 연못에서 낚은 물고기, 수족관 수조에서 만난 생물, 도서관 창가에 찾아온 손님이 이 브라우저에 기록되고 공간을 옮겨도 이어집니다.

## 친구와 함께 남기는 기록 (공유 저장)

입구 근처의 **우편함**(친구에게 짧은 편지), **마을 게시판**(주민의 오늘 부탁과 친구 메모), **표지판**(함께 고쳐 쓰는 한 줄)과 수족관 **전시 수조**처럼 친구 그룹이 함께 보는 기록은 Firebase `village/{친구 그룹}/…` 아래에 저장합니다. 새 규칙은 세 공간의 `database.rules.json`에 같은 내용으로 들어 있습니다. 로그인한 방문자만 읽고, 항목마다 작성자 본인이 정해진 모양으로 한 번만 쓸 수 있습니다.

**규칙이 실제 프로젝트에 배포되기 전까지는** 쓰기가 거절되므로 각자 브라우저에만 저장되고 화면에 '이 브라우저에만 보여요'라고 안내합니다. 저장소 주인이 Firebase 콘솔(Realtime Database → 규칙)에 `winter/database.rules.json` 내용을 붙여 넣거나 Firebase CLI로 배포하면 그때부터 친구와 함께 보입니다. 배포 전에는 `npm run test:live`로 기존 규칙이 그대로인지 확인하세요.

휴대폰 접속 알림은 선택 기능입니다. [알림 서버 설정](services/arrival-notifier/README.md)에 Cloudflare Workers 무료 계정과 Telegram 봇을 연결하는 방법을 정리했습니다. `shared/arrival-config.json`의 `endpoint`가 비어 있으면 알림 요청을 보내지 않습니다. 봇 토큰은 배포 HTML·저장소에 넣지 않습니다. 알림 연결에는 별도 Cloudflare 서버를 사용하며 Firebase 요금제는 바꾸지 않습니다.

실제 휴대폰·Safari·Windows 알림 배너는 별도 확인 범위입니다. 각 공간의 `QA.md`에 자동 검사와 브라우저 확인 범위를 구분해 두었습니다.

코드 MIT. Three.js와 Jua 글꼴의 라이선스는 각 폴더 및 배포 HTML에도 포함되어 있습니다.
