# 검증 기록 · 2026-11-07

## 전시 수조 기증 (#6)

- 해파리 쉼터 뒤쪽 (12.8, -7.6)에 전시 수조를 두었다. 보는 자리 (12.6, -5.4)까지 경로가 있고 기존 세 활동 경로를 막지 않는다.
- 해리와 대화하면 '전시 수조에 기증하기'가 나온다. 도감에서 만난 생물 중 아직 전시되지 않은 것만 기증할 수 있고 생물마다 한 번이다. 기증한 생물은 수조 안을 헤엄치고 목록에 기증자 이름이 남는다.
- `shared/village-store.js`: `village/{party}/exhibits`를 구독·기록한다. 규칙이 배포되지 않아 거절되면 같은 친구 그룹 키로 이 브라우저에 저장하고 '이 브라우저에만 보여요'라고 안내한다.
- 새 규칙(세 공간 동일): 로그인 사용자만 읽기, 항목은 처음 한 번만 쓰기, `c`=항목 id, `n` 1~12자, `u`=작성자 uid, `t` 시각, 그 외 필드 거부. **실제 Firebase에는 배포하지 않았다.**
- `check-exhibit.cjs`: 수조 충돌·경로, 모든 도감 생물의 수조 모양, 해리 대화 선택지, 만나지 않은 생물·중복 기증 거부, 로컬 저장, 헤엄 범위, 공유 모드 구독 경로·친구 기증 표시·uid 기록, 쓰기 거절 시 로컬 전환, 세 규칙 파일 동일·추가 전용.
- 인앱 브라우저: 해리 대화 → 기증 창 → 바다거북 기증. 실제 Firebase는 규칙 미배포로 거절하고 '이 브라우저에만 보여요'로 안내되는 것을 확인. 조사 오류('바다거북를')를 고쳤다.

# 검증 기록 · 2026-11-06

## 바다 수조 사진 찍기

- 바다 수조의 주 행동은 촬영, 별도 손 흔들기 버튼은 친구 인사로 구분
- 자동 검사: 실제 3D 소품·양손 촬영 자세·한 번의 반짝임·사진 확인 자세·완료 후 복귀
- 다른 캐릭터의 촬영이 내 팔·카메라·반짝임을 변경하지 않음
- 실제 친구 갱신 코드가 촬영 진행을 해석하고 종료 시 카메라를 숨기며 퇴장 시 개별 반짝임 재질을 해제
- 늦은 접속은 현재 자세부터 표시하고 지난 셔터를 반복하지 않음
- 기존 규칙을 유지하며 촬영 진행의 유효 범위를 실제 Firebase에서 검사
- 실제 Firebase에 연결한 IAB·Chrome 두 브라우저에서 촬영 토끼의 카메라와 양손 자세, 친구의 촬영 중 표시 확인
- 모바일 390×844에서 촬영·확인 상태와 3D 소품, 가로 넘침 없음 확인. 일시 뷰포트는 복원
- 두 브라우저의 오류 로그 없음. 카메라 높이를 조정해 친구의 기본 시점에서도 기기가 보이도록 확인

## 겨울 마을 왕복 추가

- 공통 친구 식별자 보존과 공간별 좌표 분리, 이동 전 기존 접속 정리, 세션 기록 검증 자동 검사 통과
- 실제 Firebase를 연결한 독립 IAB·Chrome에서 겨울 마을 → 수족관 → 겨울 마을 왕복
- 먼저 건너간 친구 이름·따라가기, 닉네임과 토끼·곰 선택 보존, 목적지 자동 입장 및 2명 재회 확인
- 320×640 모바일 폭에서 따라가기 버튼과 기존 조작 버튼, 가로 넘침 없음 확인 후 뷰포트 복원
- 기존 게임 검사·알림 검사도 통과. Firebase 규칙은 변경하지 않음

## 자동 검사

- 모든 주요 장소 사이 길찾기 경로 및 구간이 수조 충돌 영역을 피함
- 세 캐릭터의 배칭 이후 크기 및 관절 동작 유지, 다른 방문객 동작이 내 캐릭터를 바꾸지 않음
- 먹이가 실제 3D 장면 객체로 생성됨, 앉기·인사 상태 전환 확인
- 수족관 식별자와 겨울 마을 기본 식별자 구분
- 단일 HTML의 스크립트 파싱, 외부 시각 자산 미사용, 배포본·다운로드본 일치
- 입장 알림 중복 억제, 재접속 조용한 처리, 권한·동의가 없는 데스크톱 알림 억제
- 실제 Firebase: 익명 사용자 두 명의 상태 읽기/쓰기, 타인의 레코드 변경 거부, 잘못된 좌표·필드 거부, 방 목록 읽기 거부
- npm 의존성 취약점 검사 0건 (npm ci 출력)

## 화면 점검

- IAB와 Chrome의 독립적인 익명 접속: 양쪽에 2명 표시, 닉네임·캐릭터·이동 공유
- 친구 입장 게임 알림, 기존 접속자는 입장 알림을 다시 띄우지 않음
- 같은 장면의 토끼와 곰, 친구 곰의 3D 손 흔들기 관찰
- 산호 정원 도착 후 먹이 주기, 손 동작·3D 먹이·모여드는 물고기 확인, 상대 화면에서 먹이 주는 중 표시
- 해파리 쉼터에 앉기, 상대 화면에서 해파리 멍 표시, 산책 복귀
- 모바일 390×844: 쉼터에 앉은 캐릭터, 가로 넘침 없음, 주요 버튼 높이 44~50px
- 모바일 320×640: 입장 폼과 전체 조작 버튼이 화면 안에 표시됨, 바닥 클릭 이동·시점 드래그 확인
- 일시적인 뷰포트 조절은 점검 후 복원
- GitHub Pages 공개 배포 완료: HTTPS 200, 원격 HTML과 로컬 배포본 내용 일치
- 공개 주소에서 입장·Firebase 연결됨 표시·3D 장면 확인, 브라우저 오류 로그 없음

## 도서관 연결 · 2026-11-07

- 도서관 추가 후 길찾기·먹이·휴식·사진 촬영·친구 동작·알림 기존 자동 검사 통과
- 세 공간의 방 접두어·좌표 분리, 도서관 → 겨울 → 수족관 → 도서관의 자동 입장·동일 이름·캐릭터 검사 통과

- 320×640 화면에서 겨울 마을·도서관 이동 버튼과 기존 수족관 조작 표시 확인
- 사진 촬영 소스와 서버 규칙은 변경하지 않음
