# 공통 마을지기와 접속 알림 점검

2026-11-07 로컬 확인. 실제 배포·휴대폰 수신은 아래 로컬 결과와 구분한다.

- `npm run build`, `npm test` 통과. 세 HTML의 공통 NPC 삽입, 단일 파일 유지, 친구 그룹·세 공간 주소 유지 확인.
- IAB의 임시 친구 그룹에서 겨울 → 수족관 → 도서관 실제 공간 이동. 다른 실제 플레이어가 없어도 도토리가 보이고 연결 인원은 증가하지 않음. 세 공간의 NPC 모델 조립·배치 확인, 콘솔 오류 없음.
- 겨울에서 도토리 대화 열기·오늘의 한마디·닫기 확인. 도서관 390×844에서 말풍선과 대화 열기·닫기 확인. 모바일 말풍선 줄바꿈 문제 수정. 스크린샷은 로컬 `.local-runs/resident-guide-mobile.jpg`.
- 도서관 VM 검사: NPC 독립 표시, 충돌체, 손 흔들기, 대화 열기·닫기가 플레이어 상태를 바꾸지 않는지 확인.
- 알림 클라이언트 검사: 설정이 비었을 때 무요청, 실제 입장 기록 성공 이후에만 요청, 지정 친구 그룹 제한, 중복·세계 이동·실패 재시도, 공개 비밀값 배제.
- Worker Node SQLite 검사 7개 통과: 정상 검증, 동시 요청과 중복 억제, 다른 방문자와 전송 간격, 잘못된 접속·권한·출처 거부, 전송 실패 재시도, 개인 대화 일회용 연결, CORS. Firebase와 Telegram HTTP는 대역이며 실제 수신 검사가 아님.
- Wrangler 4.158.0에서 예제 설정으로 배포 dry-run 통과. 실제 Cloudflare 계정·봇 비밀값·휴대폰 연결 전에는 공개 endpoint를 비워 둠.

이 문서만으로 클라우드 배포 완료나 휴대폰 수신 완료를 주장하지 않는다. 실제 PC 전원 종료나 실물 휴대폰 알림 배너는 로컬 자동 검사로 검증하지 않았다.
