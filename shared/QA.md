# 테마별 주민과 접속 알림 점검

## 알림 서버 실제 배포 · 2026-11-07

- 본인 승인 후 공식 Wrangler OAuth를 연결했다. 실제 배포에는 `account:read`, `user:read`, `workers_scripts:write`, `d1:write`, `offline_access`를 사용한다. 이름이 비슷한 `workers:write`만으로는 배포 API가 거부되어 `workers_scripts:write`로 바로잡았다. 인증 값은 OS 키링으로 보관하며 저장소에 넣지 않는다.
- Cloudflare의 전용 D1 `my-little-village-notifications`를 APAC에 만들고 세 테이블을 실제 생성했다. 다른 프로젝트와 Firebase 규칙·요금제는 변경하지 않았다.
- `my-little-village-arrivals.seonyoungyoo16.workers.dev` 배포 성공. 업로드 8.65KiB, 시작 시간 1ms. 실제 `/health` HTTP 200, 게임 출처의 사전 요청 HTTP 204와 정확한 CORS 출처 확인.
- 실제 Firebase 프로젝트에서 임시 익명 계정을 만들어 서버 측 신원 조회와 최근 입장 기록 확인이 같은 토큰으로 성공하는지 검증했다. 임시 방의 자기 접속 기록과 시험 계정 삭제도 확인했다. 원래 친구 방에 시험 캐릭터를 넣지 않았다.
- 위 확인 시점에는 Telegram 비밀값과 개인 수신 대화 연결 전이므로 `/health`는 `ready:false`다. 실제 폰 수신 완료로 해석하지 않는다. 토큰은 루프백 전용 입력창에서 직접 받아 Worker secrets로 전달한다.

## 테마별 주민으로 변경한 버전 · 2026-11-07

- 겨울의 곰 주민 밤이, 수족관의 수달 사육사 해리, 도서관의 토끼 사서 소담을 별도 모델·의상·작업 도구·대사·장소로 구분했다. 입구에서 동일 캐릭터가 따라 바라보고 반복 인사하던 구현을 제거했다.
- `shared/check-residents.cjs`는 실제 빌드 HTML을 세 공간의 충돌 지도와 함께 실행한다. 72초 동안 방문자 위치와 친구 목록을 바꾸며 주민 위치·몸 방향이 따라가지 않고 대화나 손 흔들기가 자동 시작되지 않는지 검사한다. 기존 가구와의 발 위치, 활동 동선, 입장 인원 분리, 가까이에서 요청할 때만 열리는 대화도 검사한다.
- 실제 3D 찻잔 들기·수조 안에 떨어지는 먹이·얼굴에서 떨어진 책과 책장 넘기기를 검사한다. 주민·도구·주변 소품은 테마마다 합계 14개 이하의 메시/입자 그리기로 제한한다. 실물 휴대폰 FPS 측정은 별도다.
- `npm test` 통과. 마지막 사서의 책 위치·안내 표지 조정 뒤 세 테마 주민 검사와 전체 도서관 검사도 통과했다. 책장 선택·의자 독서·귤이 교감·공간 이동 등 기존 검사도 유지한다.
- IAB의 임시 친구 그룹에서 겨울 → 수족관 → 도서관 이동 후 각 주민에게 다가가 실제 대화 열기·닫기 확인. 겨울은 오두막 앞, 수족관은 산호 수조 옆, 사서는 기존 책상 뒤에 보인다. 수족관과 도서관 콘솔 오류 없음.
- 도서관 390×844에서 사서에게 책상 너머로 말 걸기, 역할 소개, 이야기 더 듣기, 닫기 확인. 사서 얼굴과 겹치던 책갈피 안내 표지를 옮겼다. 저장 화면은 `.local-runs/themed-winter-resident.jpg`, `themed-aquarium-resident.jpg`, `themed-library-resident-mobile.jpg`다.
- 알림 서버·Firebase 규칙·공개 알림 endpoint는 이번 주민 변경으로 수정하지 않았다. 아래는 이전 공통 NPC 구현 시점의 기록이다.

## 이전 공통 NPC와 알림 서버 준비 기록

2026-11-07 로컬 확인. 실제 배포·휴대폰 수신은 아래 로컬 결과와 구분한다.

- `npm run build`, `npm test` 통과. 세 HTML의 공통 NPC 삽입, 단일 파일 유지, 친구 그룹·세 공간 주소 유지 확인.
- IAB의 임시 친구 그룹에서 겨울 → 수족관 → 도서관 실제 공간 이동. 다른 실제 플레이어가 없어도 도토리가 보이고 연결 인원은 증가하지 않음. 세 공간의 NPC 모델 조립·배치 확인, 콘솔 오류 없음.
- 겨울에서 도토리 대화 열기·오늘의 한마디·닫기 확인. 도서관 390×844에서 말풍선과 대화 열기·닫기 확인. 모바일 말풍선 줄바꿈 문제 수정. 스크린샷은 로컬 `.local-runs/resident-guide-mobile.jpg`.
- 도서관 VM 검사: NPC 독립 표시, 충돌체, 손 흔들기, 대화 열기·닫기가 플레이어 상태를 바꾸지 않는지 확인.
- 알림 클라이언트 검사: 설정이 비었을 때 무요청, 실제 입장 기록 성공 이후에만 요청, 지정 친구 그룹 제한, 중복·세계 이동·실패 재시도, 공개 비밀값 배제.
- Worker Node SQLite 검사 7개 통과: 정상 검증, 동시 요청과 중복 억제, 다른 방문자와 전송 간격, 잘못된 접속·권한·출처 거부, 전송 실패 재시도, 개인 대화 일회용 연결, CORS. Firebase와 Telegram HTTP는 대역이며 실제 수신 검사가 아님.
- Wrangler 4.158.0에서 예제 설정으로 배포 dry-run 통과. 실제 Cloudflare 계정·봇 비밀값·휴대폰 연결 전에는 공개 endpoint를 비워 둠.

이 문서만으로 클라우드 배포 완료나 휴대폰 수신 완료를 주장하지 않는다. 실제 PC 전원 종료나 실물 휴대폰 알림 배너는 로컬 자동 검사로 검증하지 않았다.
